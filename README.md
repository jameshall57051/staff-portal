# Summer School Staff Dashboard

Files: `index.html` (overview), `staff.html` (individual schedules), `admin.html` (editor), `app.js` (shared data), `manifest.json` (optional install metadata).

Upload all files to the same GitHub Pages repository/folder.

## Important
This starter version uses browser `localStorage`, so schedule edits are shared only within the same browser/device. For a real deployment where all staff phones see the same rota, connect the `app.js` data functions to a shared database such as Supabase.

## First use
Open `admin.html`, choose a date, add shifts, then return to `index.html`.
